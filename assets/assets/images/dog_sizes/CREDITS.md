# Dog size pictures

`dog_small.png`, `dog_medium.png`, `dog_large.png`

Original illustrations made for Brio (drawn with Python/Pillow on 2026-11-11):
the same cartoon dog, in Brio's teal collar, drawn at three scales (48%, 72%,
100%) on a shared baseline so the size difference is obvious.

No third-party images or stock assets are used. These files belong to the
Brio project and may be redistributed with it.
